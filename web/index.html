    실제 Kibana를 준비하고 있습니다

    Elasticsearch → 데이터 적재 → Kibana 순서로 시작합니다.

    편집기 패키지를 브라우저 CDN에서 받지 않습니다.
    Docker 안에서 실행되는 Kibana Console을 그대로 사용합니다.

    docker compose logs --tail=80 kibana1 kibana2 app
    Ctrl / Cmd + Enter 현재 요청 실행 · Ctrl / Cmd + I 정렬
    답안과 검증이 화면의 Console 실행 기록은 현재 문항에 자동 연결됩니다.

    Console에서 요청을 실행한 다음 답안 검증을 누르세요. 공식 채점기는 아닙니다.

    Kibana의 Console 문서는 클러스터별 작업장입니다. 문항별 최종 스크립트를 별도로 보관하려면 아래에 붙여 넣으세요. 비워두면 마지막 실행 기록으로 검증합니다.
